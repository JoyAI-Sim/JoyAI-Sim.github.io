# JoyAI-Sim Project Page

This repository hosts the static project page for JoyAI-Sim.

## Live Site

https://joyai-sim.github.io/joyai-sim-project-page/

## Contents

- `index.html`: project page structure
- `styles.css`: JoyAI-RA-inspired dark visual system and responsive layout
- `app.js`: sticky header, reveal behavior, media playback handling, and pointer-following glow
- `assets/`: images and media used by the page

## Local Preview

```bash
python3 -m http.server 4173
```

Then open:

```text
http://127.0.0.1:4173/
```
