JoyAI-Sim

面向 Robot ⇄ Simulation ⇄ Human 的仿真数据互转工具链，用可复现的数字孪生评估与物理一致性筛选，扩展机器人学习的数据边界。

项目主页

JoyAI-Sim 框架

JoyAI-Sim 将仿真置于具身数据金字塔的中心，用同一套工具链连接真实机器人数据、仿真数据与第一人称人类示范数据。真实机器人任务提供部署语义与成功标准，仿真环境提供可并行、可复位、可诊断的评估层，人类数据则提供规模化的行为先验与具身反馈。

这条链路包含两个方向：Robot → Simulation → Human 负责从真机任务出发构建数字孪生，并用人类体感反馈校准轨迹自然度；Human → Simulation → Robot 则把人类第一视角视频提升到仿真环境中，通过机器人约束筛选后转化为机器人视角观测和轨迹数据。

可规模化的模型测评

在真实机器人侧，JoyAI-Sim 以 AgiBot G1 的长时序桌面整理任务作为部署锚点。任务要求模型理解语言指令、区分物体类别、选择正确目标区域，并在多步操作中保持稳定的抓取、搬运和放置能力。单纯依赖真机循环会带来低吞吐、难复现和高人工成本，因此系统先把任务重建为可批量运行的仿真评估环境。

数字孪生对齐机器人本体、场景资产、相机、光照、控制链路与任务判据，使模型可以先在仿真中进行高通量筛选，再回到真实机器人做最终验证。这样，失败不再只表现为一个总成功率，而可以被归因到机器人初始姿态、物体布局、物体实例、背景表面、光照或语言表达等具体扰动轴。

Human → Simulation → Robot 数据增值

JoyAI-Sim 将海量第一人称人类示范提升到仿真环境中，使原本与具体机器人本体无关的行为视频可以被重新解释为可检查、可重放、可筛选的任务过程。系统先从人类视频中抽取手部运动、接近方向、抓取阶段和交互区域，再在仿真中引入机器人本体约束完成重定向。

随后，仿真器根据关节限制、可达空间、碰撞、夹爪范围、接触时序和目标区域完成度进行物理可行性筛选，只保留能够被机器人执行的轨迹，并渲染为机器人视角观测。这样，人类行为数据不只是被“看见”，而是被转化为可以进入机器人学习流程的训练资源。

多种情景下的鲁棒性

JoyAI-Sim 不把鲁棒性简化为单一平均分，而是将评估拆解到可控扰动维度。真实机器人提供最可信的部署信号，仿真环境则用于大规模复现、重置和扰动。两者结合后，研究者可以更快发现策略在感知、接近、抓取、搬运、放置或语言 grounding 中的薄弱点。

  • SimReady 资产库覆盖 295 个细粒度类别、53,661 个资产实例，其中 Home 类占 62.4%。
  • 仿真数据生成结合虚拟遥操作、FSM、IKFlow 和强化学习，覆盖从种子示范到自动探索的多个阶段。
  • 人类体感反馈用于识别逐帧评估器难以发现的全局策略偏差，例如接近路径不自然或阶段过渡缺少预调整。
